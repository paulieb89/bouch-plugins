# Character performance

Create a character that serves the brief, can be produced with available assets and can be recognized across performances. Use this guidance for character identity, voice and performance; for short videos, a short-form production workflow can additionally cover story, captions, editing and delivery when available. Either can be used independently. Do not assume a particular art style, voice provider, animation model or production stack.

## Design and preserve identity

- Establish the character's role, personality, audience and medium. Define visual and vocal traits that distinguish them from the other characters. Use references with clear provenance and check rights for intended use.
- Create or select a reviewable reference; retain the approved reference, key traits, voice choice, relevant settings and evidence in the project. A flat image is not a rig; verify what can actually be animated.
- Where identity across scenes matters, test repeatability with the same character and compare outputs with the approved reference. Assess likeness and texture, clothing, eyes, mouth and unintended added features. For an ensemble, check that characters remain visually distinct in the same setting.

## Give the character a voice and performance

- Audition voices against the role. Verify the voice identity and actual access in the runtime that will generate speech; a successful call does not by itself establish that a provider used the selected voice. For multiple speakers, check distinct voices, speaker identification, relative loudness and dialogue timing. Record model, voice, settings, source, and user judgments; don't imply a voice is approved merely because it is available.
- For dialogue-led work, use a short table read to assess voice contrast and timing before generating expensive animation. Preserve script, settings and individual takes; matching inputs do not guarantee identical delivery.
- Select a performance method based on the actual reference and output: for example a layered rig, authored animation or a generation service that accepts the chosen audio. Verify whether audio is driving the performance or merely a style reference. Compare real results before asserting lip-sync or consistency.
- Before paid production, check access, model input requirements, estimated cost and budget. For long-running generation use a recoverable job where supported: retain operation IDs before waiting, disable unsafe automatic retries, and keep required inputs available until the job finishes. Protect credentials and respect user-authorized sharing.

## Review and carry forward

- Review rendered frames across the performance, the full sequence and audio when possible. Separate automatic checks and sampled frames from human judgment of voice, acting, timing, lip-sync and personality.
- Preserve the source, references, prompts or settings, outputs, provenance, costs, limitations and next decision. Record user feedback separately from agent observations. Do not treat one successful shot as proof that the character stays consistent across a series.
